### Tips for Customizing This Description:
*   **If it requires a C-Wire:** Make sure to state clearly whether a C-Wire is required or if an adapter/extender is included in the box (this is the #1 question customers have).
*   **If it has Eco-Rebates:** Add a note stating: *"Eligible for local utility company rebates—check your zip code to save up to an extra $100 instantly."*
