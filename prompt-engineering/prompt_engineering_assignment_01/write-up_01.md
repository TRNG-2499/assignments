# Analysis

- Techniques were daisy chained in pairs (walked) down the list for the water bottle prompts. First three and final three techniques were used for the headphone and houseplant prompts respectively. All occurred in lockstep (sequence matching list) around/after the seed prompt ("Write a product description for a [product]").
- Role prompting had no apparent effect. Context directly informed output contents. Constraints introduced limitations that seemed to force some creativity, especially in water bottle v4. Shots (examples) were latched onto almost verbatim (see houseplant entry). Format was adhered to when specified, so it reliably dictated output shape.
- Model basically ignored the entirety of the first houseplant prompt except for one example. Explicitly instructing it not to use either example fixed this in the second iteration.
- Combining a couple shots (examples) and a hyper-specific output format had the most dramatic effect. Together these formed lenses that focused output on what is most *desired* by the prompt. Best guess as to why is more the lack of other constraints, which may have distracted in other runs.
