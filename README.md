# assignments

Coding Challenge Assignments and other activities to be completed by associates in Revature Training TRNG-2499



##### Deliverable Format

Your solutions or other deliverables for assignments are detailed within each assignment's instructions. Your deliverables should be provided within the same folder as the assignment, and should be pushed to your named branch on this repository. Your branch should follow this format:

"firstname-lastname" (all lowercase, first and last name separated with a dash)

i.e.

"Bob Smith" would have a branch named: "bob-smith"



Ex:

* 'java\_assignment\_01' includes a 'solution.java' file
* This is pushed to your 'firstname-lastname' branch
