# Coding Challenge Log

## Objective

Build a habit of practicing coding challenges regularly, and keep a simple record of your progress over the course of training. Tracking what you have solved, and how hard it was, helps you see your growth and spot topics worth revisiting.

## Instructions

- This is an **ongoing activity**, not a one-time task. You will create your log now, and keep adding to it for the duration of the training program.
- Create a log file in one of the following formats (your choice):
  - A CSV file
  - An Excel spreadsheet
  - A text document of some kind (for example, a `.txt` or `.md` file)
- Each time you complete a coding challenge on HackerRank (or an equivalent platform, such as LeetCode, Codewars, or Exercism), add a new entry to your log. A challenge counts as completed once you have a working solution that passes the platform's tests.
- Every entry must include, at minimum:
  - The **name** of the challenge
  - The **difficulty** of the challenge, using the difficulty label shown on the platform (for example, Easy, Medium, or Hard)
  - The **date completed**, recorded in a consistent date format (for example, `2026-11-06`)
  - The **programming language** you used to solve the challenge (for example, Java or Python)
  - The **Coding Challenge platform** you used (HackerRank, LeetCode, etc...)
- Keep your log in a consistent format so that every entry is recorded the same way, and new entries are easy to add.
- Keep the log in a location you can easily reach and share (for example, in your own repository or a shared folder), and update it as you go rather than all at once at the end. Your trainer may ask to see it at any point during training.

## Example Interactions

**Example 1 — CSV file**
```
challenge_name,difficulty,date_completed,language,platform
Solve Me First,Easy,2026-01-02,Java,HackerRank
Simple Array Sum,Easy,2026-01-02,Java,HackerRank
Birthday Cake Candles,Easy,2026-01-04,Python,LeetCode
Climbing the Leaderboard,Medium,2026-01-06,Java,HackerRank
```

**Example 2 — Text document**
```
Coding Challenge Log

1. Solve Me First - Easy - 2026-01-02 - Java - HackerRank
2. Simple Array Sum - Easy - 2026-01-02 - Java - HackerRank
3. Birthday Cake Candles - Easy - 2026-01-04 - Python - LeetCode
4. Climbing the Leaderboard - Medium - 2026-01-06 - Java - HackerRank
```

**Requirements**
- You are expected to complete at least 2 coding challenges per week throughout this course 
  - Ideally, you will complete 5 per week - one per workday.
- Upload your log to this directory under your branch on this repository
- Logs will be checked each Friday.
