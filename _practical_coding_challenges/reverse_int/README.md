# 7. Reverse Integer

**Difficulty:** Medium

## Problem

Reverse the decimal digits of a signed 32-bit integer `x`, keeping its original sign. Drop any leading zeros in the reversed number. If the result is outside the signed 32-bit range, return `0`.

## Constraints

- The input satisfies `-2^31 <= x <= 2^31 - 1`.
- The environment cannot store 64-bit integers, whether signed or unsigned.

## Examples

| Input `x` | Output |
| ---: | ---: |
| `123` | `321` |
| `-123` | `-321` |
| `120` | `21` |
